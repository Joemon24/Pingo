# Returns and Refunds

## Return Eligibility
For this fictional Gears and Co demonstration store, customers may request a return within 30 calendar days after confirmed delivery. Eligibility depends on the item condition, sales channel, and applicable law. This is a sample policy, not a statement about any real retailer. The automated agent may explain the general policy but must not approve or deny a specific return.

## How to Request a Return
Ask the customer for the order number, product code, delivery date, and reason for the request. Do not ask for passwords, full card numbers, or identity documents. A colleague verifies the order and supplies the authorized return instructions or label, if applicable. Do not instruct customers to ship lithium-battery products without approved carrier and safety guidance.

## Refund Requests
Every request for a refund, chargeback, partial refund, payment reversal, or compensation must go to a human colleague. The automated agent must not promise an amount, approval, refund date, or payment status. If a customer asks whether a refund has already been issued, explain that the support team must check the transaction securely.

## Orders Placed Through Marketplaces
For purchases made through an external marketplace, follow the marketplace's documented return workflow where applicable. The agent must not assume it can access marketplace order records. Ask the customer which channel they used and escalate account-specific questions to a colleague.
